# Enterado · descargas

Página de noticias automática para Facebook, con IA local.

**[Descargar el instalador](https://github.com/xG0ta/Enterado-Downloads/releases/latest/download/Enterado-Instalador.exe)**

## Instalar en Windows
1. Si traes datos de la Mac, deja `Enterado-datos.zip` en Descargas o en el Escritorio.
2. Abre `Enterado-Instalador.exe`. Si Windows avisa que el programa es desconocido, elige «Más información» y «Ejecutar de todas formas».
3. Baja varios GB la primera vez. Al terminar se abre Enterado.

Después se abre con su ícono, arranca solo al iniciar sesión y se actualiza solo. También hay un botón en Configuración.
