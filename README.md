# Enterado · descargas

Página de noticias automática para Facebook, con IA local.

**[Descargar la última versión](https://github.com/xG0ta/Enterado-Downloads/releases/latest/download/Enterado.zip)**

## Instalar en Windows
1. Descomprime `Enterado.zip`.
2. Si traes datos de la Mac, pon `Enterado-datos.zip` en esa misma carpeta.
3. Abre `Instalar-Windows.cmd` y sigue las preguntas. Baja varios GB la primera vez.

Enterado arranca solo al iniciar sesión y se actualiza solo. También hay un botón en Configuración.
